# Agent skills

### Issue tracker

Issues 作为 markdown 文件存放在本 repo 的 `.scratch/<feature>/` 下（local-markdown 约定）。See `docs/agents/issue-tracker.md`.

### Triage labels

使用五个默认 triage labels：`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`（role 与 label 字符串相同）。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout：repo 根目录一个 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.
