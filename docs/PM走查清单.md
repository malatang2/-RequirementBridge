## 走查项（按用户旅程顺序）

### 1. 登录与项目
- [ ] 登录页能正常渲染，表单可填写
- [ ] 登录后跳转到 Dashboard
- [ ] 能新建项目（填名称/描述/规范上下文）
- [ ] 能切换项目（左上角下拉）
- [ ] 登出可正常回到登录页

### 2. 会议模块
- [ ] 进入"会议"列表，能看到已有会议或空态提示
- [ ] 点"新建会议"，能切换"粘贴文本/上传音频"
- [ ] 粘贴一段会议文本，提交后跳转详情页
- [ ] 详情页显示"AI 正在提取…"loading
- [ ] 约 10-15s 后刷新出四类分组 + 摘要
- [ ] 条目带原文引用，引用内容合理
- [ ] hover 条目能看到"编辑/删除"，编辑能保存
- [ ] 点"+ 添加"能手动新增条目
- [ ] 点"导出 Markdown"能下载文件
- [ ] **主观**：提取的条目是否准确？分类是否合理？负责人识别对吗？

### 3. API 设计器
- [ ] 进入"API 设计"列表
- [ ] 新建设计，输入业务需求，提交
- [ ] 详情页显示"生成中…"loading
- [ ] 约 10-15s 后显示生成的 YAML
- [ ] 代码视图可编辑，实时校验绿条/黄条
- [ ] 可视化视图（Swagger 卡片）正常
- [ ] 点"保存为版本"能保存
- [ ] 点"重新生成"能重新生成
- [ ] 导出 YAML / JSON 能下载
- [ ] **主观**：生成的接口是否符合预期？字段命名规范吗？

### 4. 反馈洞察
- [ ] 进入"反馈"列表
- [ ] 新建分析，粘贴多条反馈（每行一条）
- [ ] 详情页显示"AI 正在聚类分析…"loading
- [ ] 约 15-20s 后显示统计卡 + 图表 + 主题
- [ ] 统计卡数字合理（总数/主题数/高优/负面占比）
- [ ] 条形图按频次降序，饼图情感分布
- [ ] 主题卡可编辑/合并/删除
- [ ] 点"生成需求草稿"，勾选主题，生成成功跳转草稿页
- [ ] **主观**：聚类合理吗？主题命名清晰吗？优先级建议恰当吗？

### 5. 通用体验
- [ ] 页面加载速度可接受
- [ ] 操作有 loading 反馈（不卡死）
- [ ] 错误情况有提示（如网络异常）
- [ ] 移动端窗口下布局不崩（可缩小浏览器窗口看）
