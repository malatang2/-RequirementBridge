## 0. 设计约定

- **技术栈映射**：所有组件用 shadcn/ui（Card / Button / Dialog / Tabs / Table / Toast / Sheet）。
- **布局**：响应式。桌面 ≥1024px 显示左侧栏；移动端侧栏折叠为 Sheet 抽屉。
- **主题**：Light/Dark 切换（右上角图标）。
- **状态统一**：所有 AI 操作有 loading 文案 + status 状态条；失败有红色 Toast + 重试按钮。
- **图例**：`[ ]` 按钮 / `( )` 单选 / `▾` 下拉 / `◉` 选中 / `▢` 复选框 / `≡` 菜单。

## 8. 通用交互规范

### 8.1 Toast 与错误

- **成功**：绿色 Toast（如"导出成功"），3s 自动消失。
- **失败**：红色 Toast + 错误信息；`retryable=true` 时附"重试"按钮。
- **AI 进行中**：页面级 loading 文案（对应 status），如"AI 正在提取决策与待办…"。

### 8.2 表单校验

- 必填项失焦即校验，错误内联红色文字。
- 提交时再次全量校验，首个错误项聚焦。

### 8.3 空态 / 加载态

- 空态：插图 + 引导文案 + CTA（如"还没有会议，[新建一场]"）。
- 加载态：Skeleton 占位（列表）/ Spinner（按钮）。

### 8.4 响应式断点

| 断点 | 行为 |
|---|---|
| ≥1280px | 侧栏常驻，内容三栏 |
| 1024-1279px | 侧栏常驻，内容两栏 |
| 768-1023px | 侧栏折叠为 ☰ 抽屉，内容单栏 |
| <768px | 全部单栏，表格转卡片 |
