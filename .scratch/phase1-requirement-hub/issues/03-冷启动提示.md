#### 模式一：纯函数校验 seam —— 仿 `src/lib/projects.ts`

- 输入参数用 `{ name?: unknown; ... }`（unknown 而非具体类型，内部 typeof 收窄）
- 返回判别联合 `{ ok: true; value: RequirementInput } | { ok: false; error: string }`
- 校验：trim 后非空、长度上限
- 照这个模式写 `src/lib/requirements.ts` 的 `validateRequirementInput`（标题非空+≤200字、内容非空、priority 默认 medium、lifecycle 默认 draft）
- 还要加展示配置常量（`LIFECYCLE_LABELS`、`LIFECYCLE_ORDER`、`SOURCE_LABELS`），UI 复用

#### 模式二：Server Actions 五段式 —— 仿 `src/app/dashboard/projects/actions.ts`

读取这个文件，它的结构是模板：
1. 文件头 `"use server"`
2. 统一响应类型 `type RequirementActionResult = { ok: true; requirement } | { ok: false; error }`
3. 校验（调 lib 纯函数）
